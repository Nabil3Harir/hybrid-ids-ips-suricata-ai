# Methodology

## 1. Network Traffic Monitoring with Suricata

Suricata is used as the network monitoring and signature-based intrusion detection component.

It analyzes network traffic and generates alerts based on configured detection rules.

## 2. Random Forest

A Random Forest Machine Learning model is used to classify network traffic and identify malicious activity.

The model learns statistical patterns from network traffic features.

## 3. Bidirectional LSTM

A Bidirectional LSTM model is used to analyze temporal patterns in network traffic.

It processes sequences in both directions to improve the detection of complex attack behaviors.

## 4. Hybrid Decision Fusion

The predictions generated by Random Forest and Bidirectional LSTM are combined using a weighted decision-fusion approach.

This allows the system to benefit from both statistical classification and temporal pattern analysis.

## 5. Automatic Suricata Rule Generation

The project includes an automatic rule-generation mechanism based on discriminative patterns identified by the Machine Learning model.

The generated rules can then be used by Suricata for signature-based detection.

## 6. Evaluation

The system was evaluated using the CICIDS2017 dataset.

The project evaluation achieved an F1-Score above 98% with a false-positive rate below 2%.
