# Project Overview

## Project Title

Hybrid Intelligent IDS/IPS for Cyberattack Detection

## Objective

The objective of this project is to design and implement a hybrid Intrusion Detection and Prevention System combining traditional signature-based detection with Machine Learning and Deep Learning.

## Main Components

- Suricata
- Random Forest
- Bidirectional LSTM
- Hybrid Decision Fusion
- Automatic Suricata Rule Generation

## Dataset

The system was evaluated using the CICIDS2017 dataset.

## Main Results

- F1-Score: >98%
- False Positive Rate: <2%

## Technologies

- Python
- Suricata
- Machine Learning
- Deep Learning
- Random Forest
- Bidirectional LSTM
- Linux
